## Setup
Run steps will be added after the scaffold is merged (see the README setup issue). Planned:
1. Install Node 20 and MongoDB.
2. Copy `.env.example` to `.env` in `server/` and fill in the values.
3. `npm install` in `client/` and `server/`.
4. `npm run seed` in `server/`, then `npm run dev` in both folders.
