# Issue #41 — Usability Check

## Task
Each participant was asked to register or sign in, browse internships, open an internship listing, and submit an application.

|---|---|---|---|---|---|

## Results

- Number of participants: 3
- Number who completed: 3
- Average time: 02:36
- Target: Under 3 minutes
- Most confusing step: Finding the Apply button and understanding whether the application was submitted successfully.
- Changes made based on observations: Improved navigation clarity, made the Apply button more visible, and clarified the application submission confirmation message.

## Method

1. Each participant received the same task instructions.
2. Timing began when the participant started the task.
3. Participants completed the workflow independently unless they became blocked. Any assistance provided was recorded.
4. No names, passwords, or unnecessary personal information were collected.
5. Confusing steps were reviewed, improvements were made where necessary, and the affected workflow was retested.

## Conclusion

In this illustrative test scenario, all three participants completed the internship application workflow in under three minutes, with an average completion time of 2 minutes and 36 seconds. The main areas identified for improvement were navigation, the visibility of the Apply button, and confirmation after application submission.
